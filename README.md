# FitZone — Фитнес-клуб: онлайн-запись и управление тренировками

[![License](https://img.shields.io/badge/license-MIT-green)](LICENSE)
[![WordPress](https://img.shields.io/badge/WordPress-6.x-blue)](https://wordpress.org/)
[![PHP](https://img.shields.io/badge/PHP-8.x-777BB4)](https://php.net/)

Сайт для фитнес-клуба с личным кабинетом, расписанием групп и записью к тренерам. Реализован на **LAMP + WordPress** с контролем версий через **GitHub**.

---

## 🎯 Для кого этот сайт

Сайт создан для людей, которые хотят:
- Найти подходящую фитнес-программу (похудение, набор массы, растяжка).
- Выбрать тренера по специализации и опыту.
- Записаться на пробную тренировку онлайн.

**Целевая аудитория:**
- Мужчины и женщины 18–45 лет.
- Начинающие и продвинутые.
- Живущие в городе, где находится клуб.

---

## 🧭 Карта сайта (страницы)

| Страница | Содержание |
|----------|------------|
| **Главная** | Призыв к записи, выгоды клуба, акции, фото зала, видео-приветствие |
| **Программы** | «Снижение веса», «Силовой фитнес», «Растяжка», «Восстановление после травм» — длительность, стоимость |
| **Тренеры** | Карточки: фото, стаж, специализация, сертификаты, кнопка «Записаться» |
| **Расписание** | Таблица: день недели / время / тип занятия / тренер / свободные места |
| **Блог / Статьи** | Советы: «как не бросить спорт», «5 упражнений для спины», «питание до и после» |
| **Контакты и клуб** | Адрес, схема проезда, график работы, телефон, форма обратной связи, соцсети |
| **Личный кабинет** (только для зарегистрированных) | История записей, отмена тренировки, любимые программы, уведомления |

---

## ⚙️ Что умеет делать сайт

- ✅ Показывать список тренеров и программ с **фильтром по направлению** (йога / силовая / кардио).
- ✅ Принимать **заявки и онлайн-запись** через форму: выбор даты, времени, тренера, услуги.
- ✅ Показывать **календарь занятости тренера** — клиент не сможет записаться в пустой слот.

## 🛠 Технологии

### LAMP (основа сервера)

| Компонент | Роль |
|-----------|------|
| **Linux** | Серверная ОС (надёжная, бесплатная) |
| **Apache** | Веб-сервер — обрабатывает запросы и отдаёт страницы |
| **MySQL** | База данных — хранит тренеров, программы, записи пользователей |
| **PHP** | Язык генерации динамического содержимого (формы, личный кабинет) |

### WordPress (CMS)

- Готовая система управления контентом.
- Администратор клуба сам меняет тексты, добавляет тренеров, редактирует расписание **без программиста**.
- Плагины для записи:  
  `WPForms` + **Amelia** (специализированный для фитнеса).

### GitHub (контроль версий)

- Весь код (тема, доработки плагинов, стили) хранится в репозитории.
- Позволяет разработчикам работать совместно, откатывать ошибки, разворачивать обновления на сервере через `git pull`.
